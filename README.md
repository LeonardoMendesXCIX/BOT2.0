# JARVIS BOT2.0 - IA Autônoma, Moderação Rigorosa & Divulgações Programadas

## 🚀 Funcionalidades Principais
1. **Identificação Precisa via @:** Resolução de números e menções diretamente via `@+número` e `@` nativo do WhatsApp.
2. **Reconhecimento do Criador:** Identificação configurada para Leandro (`@+5511927018683`).
3. **Configuração Isolada por Grupo:** Cada grupo possui controle independente de funções.
4. **Controle Mestre `!bot on` e `!bot off`:** Liga ou desliga completamente o bot por grupo.
5. **Anti-Link Ban Imediato (`!antilink`):** Deleta a mensagem com link e expulsa o membro imediatamente.
6. **Divulgação Programada (`!divulga`):** Horário de links liberados com pausa automática do Anti-Link.
7. **Reconhecimento de Administradores (`!admins` ou "quem são os admins"):** Marca todos os administradores com `@+número`.
8. **Consciência Situacional Jarvis & Memória 30min:** Cluster de memória em tempo real com expiração automática de 30 minutos e intervenção autônoma.
9. **Memes a cada 2h (`!meme img`), Troll com IA (`!troll a`), Megafone (`!megafone`), Anti-Ghost 10min (`!antighost`) e Horários de Abertura/Fechamento (`!abrir` / `!fechar`).**
